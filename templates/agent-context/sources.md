# Sources

## Purpose

Record every source used to build company context.

| ID | Source | Type | Location | Date accessed | Reliability | Notes |
|---|---|---|---|---|---|---|
| SRC-001 |  | Website / public asset / user-provided file / interview answer |  |  | Primary / public / user-confirmed / stale / unverified |  |

## Reliability Definitions

- `Primary`: company-owned source or authoritative system.
- `Public`: public-facing asset, useful as observed messaging but not automatic truth.
- `User-confirmed`: confirmed directly by the company/user during setup.
- `Stale`: likely outdated.
- `Unverified`: not yet confirmed.
