## Goals (12-month, set 2026-06)

1. First-session completion rate: meaningful lift over the gated baseline.
2. Day-35 subscription conversion: from 5.46% toward 8%.
3. Lifecycle flows live: onboarding, lapsed, hardware post-purchase.
4. Organic: two SEO pillars ranking on tier-1 terms.

## Funnel Definitions

- **Activation:** completed first audio session (not app open).
- **Conversion:** paid subscription start (trial start is a separate event).
- Attribution: last-touch for now, acknowledged as crude; revisit post-seed.
